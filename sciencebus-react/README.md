# Science Bus React Prototype

Scratch React prototype for the public Science Bus website.

## Stack

- React + TypeScript + Vite
- Material UI for accessible components and theming
- Tailwind CSS v4 for layout and utility styling
- Framer Motion for React Bits-style motion
- Local `src/components/react-bits/*` animated components inspired by the React Bits copy-into-project model

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Notes

This project is separate from the existing PHP site. It does not change the live InfinityFree deployment.
